Connect WhatsApp number to MALAC (one-time setup)

This page runs Meta’s Embedded Signup with coexistence: it connects the WhatsApp Business app number +92 323 6016684 to the Cloud API without removing it from the app. Meta converts the account during this flow — linking it from Business Settings alone does not do that.

The Embedded Signup configuration ID is not set. Open this page with ?config_id=YOUR_ID in the URL, or paste the ID into the CONFIG_ID constant in this file. The ID is created in the Meta app dashboard (see docs/whatsapp-embedded-signup-runbook.md).
You are not signed in as Super Admin in this browser. Sign in at /admin first (same browser), then come back — the result of this flow contains a live access token, so the server only accepts it from the Super Admin account.
  1. Click Connect WhatsApp below.
  2. In the Meta popup, log in with the Facebook account that owns MALAC Store.
  3. Choose the option to connect your existing WhatsApp Business app account, and type the number +92 323 6016684 manually if asked (do not pick a dropdown entry that says “Ineligible”).
  4. Confirm in your WhatsApp Business app (enter the code / tap “Connect to the Business Platform” → Confirm) and finish the popup.
  5. Keep this tab open — the result appears below automatically.

Do NOT close the popup early and do NOT use the classic SMS “Verify” flow anywhere — coexistence numbers are already registered and must never be migrated or deregistered.
